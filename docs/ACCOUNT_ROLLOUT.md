# AIOS Account Rollout and Verification

This document explains how to distribute the approved AIOS-7 baseline and AIOS-P01 across ChatGPT contexts. Publishing this repository does not modify any account or project settings.

## Account setup

1. In ChatGPT open Settings > Personalization > Custom Instructions.
2. Inspect the existing text before editing. Incorporate the relevant portable directive from [ACCOUNT_INSTRUCTIONS.md](ACCOUNT_INSTRUCTIONS.md) without deleting important user preferences.
3. Enable customization, save, reopen settings, and confirm the persisted text.
4. Open each relevant Project > Project settings > Instructions. Preserve project-specific rules while adding compatible AIOS guidance, as these may override account preferences.
5. Test both an existing chat and a new chat in ordinary and project contexts, including shared projects separately.

## Scope limits

ChatGPT's official Help Center states that updated custom instructions apply to current and new chats, while project-specific instructions override account-wide preferences. Shared projects can have additional memory/personalization isolation. Review these separately.

- Custom Instructions: https://help.openai.com/en/articles/8096356-custom-instructions-for-chatgpt
- Projects: https://help.openai.com/en/articles/10169521-using-projects-in-chatgpt
