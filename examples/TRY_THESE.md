# Try AIOS-7

Paste [the master prompt](../AIOS7_PROMPT.md) into a new chat, then try these natural-language requests:

1. “I have three strategies to launch my project. Compare trade-offs and let me select provisionally, without treating selection as approval.”
2. “Review this contract and separate verified text, unknown facts and negotiation priorities.”
3. “Plan a three-stage project with dependencies and a clear next action.”
4. “I have sales data. Help me explore scenario assumptions and compare results.”
5. “Teach me the essentials of project finance, then test me with a question.”
6. “Show what was actually executed and verified in this task, separate from suggested next steps.”

Expected interaction patterns are **not guaranteed UI rendering**. If the environment does not support useful interactive components, AIOS should fall back and offer a transfer-note option where appropriate.
