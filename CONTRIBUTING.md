# Contributing to AIOS-7

Contributions are welcome: useful interaction designs, prompt improvements, counterexamples, accessibility and compatibility findings, and reproducible benchmarks.

## Propose a RAB pattern

Include its ID (provisional if new), task trigger, user benefit, visual structure, inputs, state, action semantics, accessibility, fallback, acceptance criteria, and whether it was actually tested.

## Integrity rules

- Do not include credentials, confidential client files, personal secrets or private conversations.
- Do not present mockups as verified behavior.
- Never claim that a pattern works on all ChatGPT accounts from one example.
- Separate user's provisional choices from explicit approvals and tool-verified outcomes.
- Provide reproduction instructions for reported issues.

Fork the repository, open an Issue or Pull Request, and refer to the pattern registry. MIT license applies to contributions unless otherwise specified.
