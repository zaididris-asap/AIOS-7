# AIOS-7 Evaluation Plan

Compare (A) ordinary ChatGPT, (B) Rich Blocks-only instructions, and (C) AIOS-7. Use the same model configuration, enabled tools, comparable tasks and predeclared acceptance criteria. Randomize or counterbalance task order.

Task families: direct Q&A, multi-option decisions, comparisons, planning, factual research, document review, execution authorization, learning, data analysis, creative work.

Record:
- Accepted tasks per human hour (primary productivity metric)
- Blind output quality (accuracy, evidence, completion)
- Time-to-accepted-result
- Number of revisions and user interventions
- Interface appropriateness and functioning controls
- Critical safety/authority failures (hard blockers)

Keep objective correctness independent of appearance scores. Do not inflate results from zero-denominator cases. A single tester can reveal UX defects but not prove a universal multiplier.

**Current results:** No completed external evaluation. All suggested performance gains are hypotheses.
